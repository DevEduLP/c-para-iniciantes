# Guia Introdutório de Programação C para Iniciantes

Material didático em desenvolvimento voltado para estudantes de Computação e Análise e Desenvolvimento de Sistemas (ADS), com explicações passo a passo, exemplos comentados e capturas de tela.

## Objetivo
Construir uma base sólida em programação estruturada e gerenciamento de memória, partindo dos fundamentos da linguagem C até tópicos essenciais de baixo nível.

## Conteúdo Programático

- [ ] **Módulo 01:** Introdução à Linguagem C 
- [ ] **Módulo 02:** Variáveis, Tipos de Dados, Operadores e Entrada/Saída (`printf` e `scanf`)
- [ ] **Módulo 03:** Estruturas Condicionais (`if`, `else`, `switch`)
- [ ] **Módulo 04:** Estruturas de Repetição (`while`, `do-while`, `for`)
- [ ] **Módulo 05:** Vetores, Matrizes e Manipulação de Strings
- [ ] **Módulo 06:** Funções, Escopo e Passagem de Parâmetros
- [ ] **Módulo 07:** Ponteiros e Alocação Dinâmica de Memória (`malloc`, `calloc`, `free`)
- [ ] **Módulo 08:** Estruturas (`struct`) e Tipos Definidos (`typedef`)
- [ ] **Módulo 09:** Manipulação de Arquivos em C (`fopen`, `fread`, `fwrite`, `fclose`)
